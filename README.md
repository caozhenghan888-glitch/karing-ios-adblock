# iOS 专属 Karing 纯净去广告与防摇一摇实战指南

> **基于 iOS 网络扩展内核与实时流量抓包的无痛去广告方案**  
> 经实测验证：完美去除小白盒子 App、哈啰出行（开屏摇一摇/弹窗）等国内主流商业 App 广告，核心业务与地图、扫码开锁、打印功能 100% 正常。

---

## 一、方案核心原理与优势

### 1. 为什么选择 Karing？
- **系统底层接管**：利用 iOS 的 Network Extension 框架，无论 App 走常规系统 DNS 还是加密 HTTPDNS/IP 直连，流量都必须经过 Karing 内核。
- **域名级精准丢弃（REJECT）**：国内绝大多数生活、出行与工具类 App（85%+）接入的是第三方广告联盟 SDK（优量汇、穿山甲、极光推送、友盟统计）。核心业务域名与广告下发域名完全物理隔离。
- **零功耗无感拦截**：广告请求在手机本地直接被掐断，App 内部超时后直接跳过 5 秒倒计时秒进主页，不浪费流量与电池。

## 二、精简高效拦截规则集（直接复制）

在 Karing 中创建 **「🛑 广告拦截」** 自定义规则，并将出站行为设为 **`REJECT`**。

### 1. 核心域名后缀规则库 (`domain-suffix`)

```text
gdt.qq.com

# 2. 字节跳动广告联盟（穿山甲 - 极高频开屏广告与摇一摇）
pglstatp-toutiao.com
pangolin-sdk-toutiao.com
pangle.io

# 3. 快手广告联盟
adkwai.com
e.kuaishou.com

jpush.cn

# 5. 友盟统计与陀螺仪摇一摇打点（阻断设备指纹与动作传感器上报）
umeng.com

# 6. 一帆互联广告联盟（实测小白盒子/白兔打印核心广告源）
yfanads.com

# 7. 百度百青藤移动广告
mobads.baidu.com

```

### 2. 重点避坑白名单（千万不要拦截！）
- ❌ **`cdn-h.gongfudou.com` / `gongfudou.com`**：小白打印盒子的核心界面代码 CDN 与控制中枢，拦截会导致小程序或 App 白屏崩溃。
- ❌ **`wxsnsdy.wxs.qq.com` / `sni.cdn.weixin.qq.com`**：微信核心前端架构与通信组件，拦截会导致微信小程序资源加载失败。
- ❌ **`itunes.apple.com`**：苹果官方 App Store 比对接口，拦截会导致全系统软件更新与下载瘫痪。

## 三、Karing 配置实战流程

### 第一步：创建自定义分流组
1. 打开 Karing App，点击底部菜单 **「分流规则」**。
2. 确保勾选/开启 **「自定义分流组」**。
3. 点击 **「添加规则」**，命名为：`🛑 广告拦截`。
4. 在 **「域名后缀」** 输入框中，粘贴上方提供的规则库。
5. 逻辑运算保持选择 **`OR`**。
6. 点击右上角 **对勾 ✔️ 保存**。

### 第二步：将拦截规则提升至第 1 优先级（核心关键！）
1. 在 **「分流规则」** 列表中，找到刚建好的 **「🛑 广告拦截」**。
2. 将出站动作由默认改为 **`REJECT`**（或 `Block` / `拒绝`）。
3. **长按右侧三条杠，将该规则拖动到最顶部（排在第 1 位）**。
   > **注意**：必须排在所有国内直连（`cn[geosite]`）的前面，否则广告流量会被抢先放行！

### 第三步：放行本地局域网（防影响内网打印）
1. 在 **「分流规则」** 顶部，确认开启 **「私有网络直连」**。
2. 确保局域网打印机（如 `192.168.3.x`）走原生直连。

## 四、动态排查与新 App 广告精准抓取法（实战工作流）

当遇到新的恶性弹窗 App 时，通过 Karing 内置的 Web 控制台在 10 秒内抓出真实广告域名：

### 1. 获取控制台访问权限
- 在 Karing 设置中开启 **Web 控制面板**（或查看本地监听地址，如 `http://127.0.0.1:3072`）。
- 记录面板中的通信端口（如 `3057`）与访问密钥 `secret`。

### 2. 抓包三步法：
1. **彻底划掉目标 App** 杀死后台进程。
2. 打开抓包监听器，重新点击启动该 App，直到广告弹窗出现。
3. 在连接记录中过滤高频的外部非业务域名（通常单次启动连击 10~30 次以上的均为广告追踪），将其域名根加进拦截列表。

## 五、方案能力边界客观说明

| 场景 | 拦截效果 | 原理解释 |
| :--- | :---: | :--- |
| **开屏 5 秒倒计时广告** | **100% 消除** | 第三方 SDK 拿不到响应直接触发超时逻辑，秒开 App |
| **开屏“摇一摇”误触** | **100% 消除** | 掐断 `jpush.cn` 与 `umeng.com` 陀螺仪数据打点，不再响应晃动 |
| **应用内悬浮窗/弹窗广告** | **95% 消除** | 拦截配置下发接口，广告位自动折叠 |
| **微信小程序插屏广告** | **不可网络层过滤** | 微信底层同域混用，强行拦截会导致页面白屏；**替代方案：使用独立 App 接收文件打印** |
| **抖音/B站信息流视频广告** | **需高级重写** | 广告与普通视频走相同流媒体 CDN，需结合 MitM 脚本过滤 |
