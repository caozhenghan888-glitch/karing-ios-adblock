## 一、AI 智能体协同抓包的核心工作流（小白必看）

传统去广告需要安装抓包根证书、配置 MITM 中间人代理，还要肉眼在几千行网络请求里翻找。  
现在有了 Karing 和 AI 智能体（如 Minis / Claude / ChatGPT），只需三步实现全自动智能排查：

```
[打开 Karing 开源 Web 面板] ➔ [复制端口与密钥给 AI 智能体] ➔ [在手机上重启目标 App 触发广告] ➔ [AI 后台秒级捕获域名并输出拦截列表]
```

### 步骤 1：打开 Karing 的开源 Web 控制面板
1. 打开 iOS 手机上的 **Karing** App。
2. 点击底部的 **「设置」**（Settings）。
3. 找到并开启 **「Web 控制面板」**（部分版本显示为 Dashboard 或外置面板开关）。
4. 点击“打开 Web 控制面板”，系统会自动在 Safari 中打开一个本地网页控制台（基于开源项目 [zashboard](https://github.com/Zephyruso/zashboard)）。

### 步骤 2：提取关键连接信息（地址、端口与密钥）
在 Safari 顶部的地址栏中，你会看到类似下面的一长串本地控制网址：
```text
http://127.0.0.1:3072/?hostname=127.0.0.1&port=3057&secret=YOUR_SECRET#/proxies
```
**只需复制整段网址，或者提取其中的 3 个核心参数**：
- **Web 访问地址**：`127.0.0.1:3072`
- **内核通信端口 (`port`)**：`3057`
- **安全密钥 (`secret`)**：`YOUR_SECRET`

### 步骤 3：把信息交给 AI 智能体
把这行信息直接发给你的 AI 智能体（比如 Minis / 拥有终端与网络能力的 AI）：
> *“我已经打开 Karing 面板了，地址是：`127.0.0.1:3072/?hostname=127.0.0.1&port=3057&secret=YOUR_SECRET XX App 的广告域名！”*

AI 智能体收到后会：
1. 自动调用 WebSocket / REST API 连入 Karing 内核的 `3057` 端口，开始毫秒级实时监听。
2. 提示你：*“抓包通道已就绪，请划掉 XX App 并重新打开！”*

### 步骤 4：手机触发与自动定位
1. 你在手机多任务后台里，把目标 App 彻底划掉关闭。
2. 重新点开该 App，让开屏广告或弹窗出来展示一下。
3. 切回 AI 聊天界面说一句：“好了”。
4. **AI 智能体会自动调取这几秒内爆发的数十条网络请求，剔除掉业务域名，精准拎出真正的广告域名！**

## 二、实战案例复盘（真实避坑沉淀）

### 案例 1：小白盒子 / 白兔打印 App 去广告
- **现象**：打开 App 强制弹窗广告、无法直接打印。
- **AI 抓包发现**：App 启动瞬间连续 20 余次请求：
  - `tracker.yfanads.com`（一帆互联广告联盟）
  - `s.baertt.com` / `qmlog.baertt.com`（白兔数据与广告分发）
- **绝杀规则**：拦截 `yfanads.com` 和 `baertt.com` 后，开屏与弹窗彻底消失。
- ⚠️ **血泪避坑点**：**千万不能拦截 `gongfudou.com`（功夫豆）！**  
  抓包时会发现有 `cdn-h.gongfudou.com`，这是小白盒子的前端 UI 核心资源，一旦误封，App 和小程序会直接白屏崩溃。

### 案例 2：哈啰出行 App 去开屏“摇一摇”与全局弹窗
- **现象**：稍微动一下手机就误触触发“摇一摇跳转广告”，首页浮层弹窗频繁。
- **AI 抓包发现**：启动瞬间产生 30 余次高频连击：
  - `tsis.jpush.cn` / `stats.jpush.cn`（极光推送长连接通道，用于远程下发弹窗）
  - `errnewlog.umeng.com`（友盟统计，用于采集陀螺仪传感器与摇一摇判定）
- **绝杀规则**：拦截 `jpush.cn` 和 `umeng.com`。
- **效果**：哈啰 App 秒开，摇一摇彻底失效，扫码开锁、骑车结算和地图找车完全不受任何影响！

## 三、Karing 配置实战（如何生效）

抓到广告域名后，在 Karing 里配置只需 30 秒：

### 1. 添加拦截规则
1. 打开 Karing 底部菜单 **「分流规则」**。
2. 开启 **「自定义分流组」**，点击新建规则（命名为：`🛑 广告拦截`）。
3. 在 **「域名后缀」** 输入框中，粘贴抓出的广告域名（参考本项目 `adblock_rules.yaml`）。
4. 逻辑运算保持选择 **`OR`**，点击右上角保存。

### 2. 规则优先级调整（最核心一步！）
- 在规则列表中，将该条规则的出站动作设为 **`REJECT`**（丢弃/阻断）。
- **按住右侧三条杠，拖动到整个规则列表的最顶端（第 1 优先级）！**
> **原理解析**：Karing 是从上到下按顺序匹配规则的。如果不拖到最上方，广告请求会被下方的 `cn[geosite]`（国内直连）抢先放行，导致拦截失败。

### 3. 放行局域网（防影响内网打印）
- 在「分流规则」页面顶部，确保开启 **「私有网络直连」**。

### 4. 副作用提醒（知情取舍）
- 本规则集对 `jpush.cn`、`umeng.com` 采用整段拦截：实测哈啰出行、小白打印的核心业务不受影响，但**其他 App 若走极光推送 / 友盟推送，通知到达可能受影响**。若发现某个 App 收不到推送，可先临时放行这两个域名验证，再决定是否长期保留拦截。

## 四、关于微信小程序广告的技术真相

很多用户问：*“小白盒子的微信小程序也能用这套方法去掉开屏 5 秒广告吗？”*

**结论：不能在网络层暴力拦截，否则会导致小程序白屏。**
- **底层原因**：微信小程序的开屏插屏广告（如京东/电商广告）是微信客户端原生组件下发的，且与小程序代码同走 `sni.cdn.weixin.qq.com` 和 `sh.servicewechat.com`。
- **最佳解法**：在微信收到试卷或文档后，点击 **「…」➔「用其他应用打开」➔ 选择「小白学习打印 App」**。由于独立 App 已被我们彻底去掉了广告，跳进 App 里打印既秒开又纯净，体验最佳！
